# AI 协作留痕

> 每个 change 在 `docs/ai-collaboration/<change-id>.md` 记录四节。
> 本文件说明格式；没有 prompt 原文时标注「无独立留痕」，不补造、不推测。

## 模板

```markdown
# AI 协作留痕：<change-id>

## 1. prompt 范围
- 授权修改的文件：
- 明确不做的事：
- 出处（引用原话或摘要）：

## 2. AI 产出
- 新增文件：
- 修改文件：
- 关键决策：

## 3. 人工修正点
- 人类改了什么：
- 驳回了什么：
- 补充了什么判断：

## 4. 回归结果
- 用例数 / 失败数：
- 证据链接：`docs/verify/<change-id>.md`
```

## 高风险判断类别（必须单独留痕）

- 字段歧义（同一词既可能是公司也可能是产品）——本项目对应：知识点命名与类型判定。
- 实体混淆（人名 / 公司名）——本项目对应：知识点与模块归属。
- 多值无标签——本项目对应：同一题多个可接受答案。
- 信息缺失时的「合理猜测」——**必须禁止**，缺失就返回空（`INV-25`/`INV-33`）。
- 行为等价判断：任何「Java 版这样写与 Python 版等价」的结论，必须附对照的 Python 测试名。
